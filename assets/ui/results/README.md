# Arte de la pantalla de resultados

Recursos originales generados el 21 de octubre de 2026 con OpenAI ImageGen para la pantalla panorámica de resultados. La captura aportada por el usuario se utilizó únicamente como referencia de tono, material y composición; no se copiaron sus textos, personaje, iconos ni diseño exacto.

- `results-parchment.png` (1440×810, RGBA): pergamino ancho envejecido dentro de un marco de madera oscura, con ornamentos japoneses discretos y centro libre para la interfaz dinámica. El margen transparente de generación se recortó antes del escalado final para que el marco alcance los cuatro bordes del lienzo 16:9.
- `result-stamp-frame.png` (640×320, RGBA): impresión rectangular de tinta bermellón, desgastada y sin texto. Los estados `APROBADO`, `ABANDONADO` y `FALLIDA` se dibujan por código para garantizar legibilidad y ortografía.

Ambos PNG conservan transparencia real fuera de la silueta del recurso. Los originales de alta resolución permanecen en el historial local de generación de Codex.
